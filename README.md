# Atlas de Hyrule

[Abrir o atlas no computador ou celular](https://chicolyra.github.io/atlas-hyrule/)

Mapa original de Hyrule com 22 regiões selecionáveis, 33 plantas locais (incluindo andares) e checklist em português para a fase infantil de Ocarina of Time no Switch 2. Site estático sem dependências. Atualizado em 16/11/2026.

## Usar

Abra o link acima no Safari ou Chrome. Para ter um atalho no celular, escolha **Adicionar à Tela de Início** no menu do navegador. Toque em uma região e marque os objetivos concluídos. As instruções ficam em **Como encontrar**. Publicação: GitHub Pages, branch main, pasta raiz.

O progresso fica em localStorage no navegador. Não há sincronização automática: use **Meu progresso** para gerar um link com as marcações, exportar ou importar um arquivo JSON. Importar permite somar ou substituir o progresso. Limpar dados do navegador remove o progresso local.

## Conteúdo e limites

43 Skulltulas da primeira infância, 9 entradas da volta ao passado (uma marcada para confirmação) e missões/melhorias/corações. A contagem é a da checklist, não uma garantia de 100% do remake. Fontes por objetivo, divergências sinalizadas.

Selecione uma região para entrar em sua planta local. Use a seleção de andar nas masmorras. Arraste, use a roda do mouse, dois dedos ou os botões para ampliar. **Ajustar** enquadra a imagem inteira sem barras de rolagem; **Tela cheia** amplia a área de visualização. As setas do teclado e os botões direcionais também movimentam o mapa.

94 dos 100 objetivos da checklist têm uma posição associada à cartografia de referência. Pontos de missões podem representar um personagem, uma entrada ou um local de entrega, conforme a observação. Personagens móveis e recompensas aleatórias não possuem uma única coordenada de coleta. Os 6 objetivos sem associação conferida permanecem na checklist e estão identificados. Não foram inventadas coordenadas para preencher essas lacunas.

**Zelda Notes:** a Nintendo documenta a conexão do serviço com o jogo, mas não foi encontrada uma API pública documentada para sincronização com sites externos. Este atlas não se conecta ao Zelda Notes. [Informações oficiais](https://www.nintendo.com/us/mobile-apps/nintendo-switch-app/zelda-notes/).
